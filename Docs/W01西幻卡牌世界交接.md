# W01 西幻卡牌世界交接

本文记录 W01“灰烬王国”当前可玩切片的联合构建与验证要点。稳定技术标识和目录仍使用 `W01_EasternHorror`，避免破坏已有传送软引用。

## 已实现玩法

- W01 从出生点到战斗庭院形成完整探索路线：流亡者营地、中世纪村落、火炬石路、黑棘隘口与返回门；运行时共组合 121 个场景网格、11 盏探索灯和四名居民，18 个 CC0 环境网格缺失时有灰盒回退。
- 守门老兵、流亡修女、奥术学者和灰烬游侠均可按 `E` 交谈，每人有中文开场、三条分支回答与告别语，并具备待机和交谈动作。
- 玩家在 W01 可按 `Q` 主动切换“世界行者 / 符文骑士”外观；战斗中禁止切换。符文骑士能按速度播放待机、行走和奔跑动作。
- 10 张起始牌组严格从 W01 自己的 `Data/Cards` 加载，不再混入 Shared 旧卡。
- 每回合 3 能量、5 手牌，支持保留、消耗、抽牌和组合效果。
- 钢铁、圣徽、奥术三印在同一回合全部点亮时触发一次共鸣：获得 1 英勇并抽 1 张牌。
- 英勇上限 3，跨回合保留；完全格挡一次敌方攻击额外获得 1 英勇。
- 终结牌“狮心裁决”消耗 2 英勇，造成 18 伤害并获得 10 格挡，保留且使用后消耗。
- 状态顺序为：基础伤害 + 力量 → 虚弱乘 0.75 向下取整 → 破绽乘 1.5 向下取整 → 格挡 → 生命。
- 首敌“黑棘誓约骑士”有 92 生命，按四步循环行动并提前显示精确意图：盾阵推进、破甲斩、黑暗誓言、审判重斩。
- 玩家伤害牌/受击和敌人攻击/强化/受击/死亡均接入现有 CC0 骨骼动作，资源缺失时不影响规则。
- 原生 UMG 以中文显示生命、能量、格挡、英勇、三印、双方状态、下一意图、卡图和规则文本。

## 联合构建顺序

1. 关闭 Unreal Editor，完整编译 `WorldWalkerPrototypeEditor Win64 Development`。
2. 编译成功后，先运行 `Scripts/import_w01_fantasy_assets.py`。
3. 再运行 `Scripts/import_w01_world_assets.py`，导入 18 个环境网格及 Cleric/Wizard/Ranger 与内嵌动作，并为四名人类角色显式生成、编译和回绑 8 个贴图材质。
4. 最后运行 `Scripts/setup_world_content.py`，生成/更新六种中文卡牌数据资产和中文敌人定义，并把已经导入的卡图写入 `Artwork`。
5. 模型或环境资源缺失时 C++ 会回退到灰盒；卡牌数据仍需第四步成功生成。

资产导入成功标记：

```text
W01_FANTASY_ASSET_IMPORT_COMPLETE cards=6/6 models=2/2
```

世界与 NPC 资源导入成功标记：

```text
W01_WORLD_ASSET_IMPORT_COMPLETE environment=18/18 npcs=3/3 animations=<N> materials=8/8 lantern=geometry_fallback
```

若完整 FBX 已经导入、只需重建白模修复材质，可在执行脚本前设置 `WORLDWALKER_W01_MATERIAL_REPAIR_ONLY=1`；成功标记为：

```text
W01_CHARACTER_MATERIAL_REPAIR_COMPLETE materials=8/8
```

内容生成成功标记：

```text
WORLD_WALKER_SETUP_COMPLETE
```

## 最小人工验证

1. 从 W00 自动穿越旋涡进入 W01，确认顶部显示“灰烬王国 · 黑棘隘口”。
2. 沿火炬道路检查营地、村落、塔楼、植被、黑棘庭院与右后方返回门；确认门洞和道路不会被碰撞封死。
3. 按 `Q` 两次并移动/停下，确认外观往返以及待机、行走、奔跑动作。
4. 与四名 NPC 逐一交谈，确认中文姓名、三个分支、继续/结束/`Esc`、双方朝向与输入恢复。
5. 靠近黑棘誓约骑士按 `E`，确认中文战斗面板、敌人生命 92、第一条意图精确显示 8 格挡和 7 伤害。
6. 确认开局为 3 能量、5 手牌、0 英勇。
7. 同回合依次使用三个不同学派，确认只触发一次共鸣、英勇 +1、抽 1 张。
8. 用格挡完全挡住一次敌方攻击，确认英勇 +1；少 1 点格挡时不奖励。
9. 英勇不足时终结牌不可点击；达到 2 后可打出、扣除 2 英勇并进入消耗堆。
10. 确认“骑士祷言”在结束回合时保留，并在下一回合补牌到 5 张。
11. 用“洞悉破绽”施加破绽后，8 伤害应变为 12，并消耗 1 层破绽。
12. 连续结束回合，确认敌方按四步固定循环行动，力量会影响后续伤害且 UI 始终预告下一步。
13. 胜负后卡牌与结束回合按钮不可操作；重新开始和返回 W00 仍正常。
