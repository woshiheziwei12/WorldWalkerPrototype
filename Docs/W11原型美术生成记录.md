## 生成方式与提示词

生成方式：OpenAI ImageGen，brand-new image generation，未使用外部作品或现有游戏画面作为参考图。

### 场地

```text
Use case: stylized-concept
Asset type: 2D game arena background for an Unreal Engine top-down roguelite
Primary request: an original Chinese xianxia secret-realm combat arena, made as a polished hand-painted 2D game background
Scene/backdrop: ancient circular jade-stone cultivation platform in a misty mountain sanctuary, subtle cracked runes, moss, shallow streams and lotus pools around the outside, bamboo and distant cloud-filled cliffs only at the outer border
Style/medium: clean stylized hand-painted 2D game art, readable shapes, restrained detail in the playable center
Composition/framing: strict 90-degree orthographic top-down view, landscape 16:9, large unobstructed central fighting area, decorative terrain confined to edges, no perspective horizon
Lighting/mood: cool moonlit teal and jade with restrained warm-gold rune accents, mystical but gameplay-readable
Color palette: deep blue-green, desaturated jade, ink gray, small amber highlights
Constraints: no characters, no creatures, no weapons, no text, no UI, no logos, no watermark, no isometric perspective, no camera tilt; the central 70 percent must remain open and low-contrast for combat readability
```

### 角色图集

```text
Use case: stylized-concept
Asset type: transparent 2D game sprite atlas for a top-down Unreal Engine xianxia roguelite
Primary request: four separate original full-body game sprites arranged in an exact 2 by 2 grid with very large transparent gaps between them
Subject: top-left is a young wandering sword cultivator in white and teal robes holding a simple jade sword; top-right is a small turquoise miasma wisp spirit; bottom-left is a squat gray stone-armored fiend with glowing amber cracks; bottom-right is a pale blue floating broken-sword wraith
Style/medium: polished hand-painted 2D game sprites, slightly chibi proportions, bold readable silhouettes, consistent scale and line treatment
Composition/framing: strict near-top-down three-quarter game view, each subject centered alone in its quadrant, complete body fully visible, identical generous padding, no overlap, no ground plane
Lighting/mood: cool jade moonlight with restrained emissive accents, readable at small size
Constraints: genuinely transparent background with preserved alpha; exactly four subjects and nothing else; no labels, no text, no borders, no UI, no decorative frame, no logos, no watermark, no cast shadows extending into another quadrant; keep all pixels of each subject well inside its quadrant
```

## 运行时策略

- `AW11ArenaBackdrop` 只在非 Dedicated Server 客户端本地生成背景，不参与碰撞、规则和网络复制。
- 玩家与敌人仍以 Flipbook 作为未来正式表现入口；当 Flipbook 为空时，才显示本轮导入的静态 PaperSprite，因此后续添加动画无需重写战斗规则。
- 玩家、敌人与背景使用分层的 Translucent Sort Priority；敌人出生高度提高到 `Z=60`，避免与场地背景发生深度冲突。
- 本轮没有生成攻击、受击、死亡动画和 VFX；看到静态角色只代表视觉占位已解决，不代表美术纵切完成。
