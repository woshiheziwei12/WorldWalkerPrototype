# W11 开场动画 Wan3 首帧生成记录

日期：2026-08-28  
用途：记录 S01–S14 实际用于 Wan3 首帧图生视频的静态画面与最终绘图提示方向。

## 共通最终提示

所有新图统一使用以下母提示：

> 原创中国仙侠游戏开场动画，严格横向 16:9，不透明画面；高级手绘二维电影概念图，国风水墨氛围与精细绘画式赛璐璐结合，克制的胶片颗粒，成人向严肃奇幻，清晰前中后景，适合五秒图生视频。禁止文字、字幕、UI、标志、水印、透明棋盘格、照片感、光滑三维感、霓虹科幻感以及现有作品角色相似性。

顾长渊镜头额外使用对应时期的既有立绘作为身份参考，但最终 Wan3 目录只保留已经合成好人物与场景的首帧。

## 各镜头最终绘图提示核心

| 镜头 | 最终画面提示核心 |
|---|---|
| S01 重生残响 | 纯黑水墨虚空中恰好四块前世倒影：雨中车窗、病床边成人手掌、无字烧焦信纸、空餐桌；不出现人脸。 |
| S02 坠入诸界 | 匿名背影灵魂在墨色世界夹缝中下坠，下面是月牙状裂隙、云海和远山，周围只有少量文明剪影碎片。 |
| S03 错误答案 | 低机位看匿名手掌在尘土中画不可读的抽象方案，玉色灵风开始吹散方案，远处山镇居民正在关门。 |
| S04 魔治人间 | 无相魔庭占领山城，黑甲监工抽取百姓灵气，天空赤红漩涡笼罩城池。 |
| S05 年轻的顾长渊 | 年轻顾长渊在隐蔽营地为伤者包扎，洞外桥梁运送难民与物资，英雄性来自照料而非威势。 |
| S06 方法而非神谕 | 顾长渊与五名普通成人围坐测试布炭滤水器、木秤和无字地形板，老妇指出问题，所有人共同试错。 |
| S07 众人之战 | 雾中梯田山谷的集体抵抗，顾长渊发出手势，盾手、弓手、医者和工匠协作，远处魔军从赤灰中逼近。 |
| S08 无明渊 | 战损顾长渊在破碎地下王庭伸手接近被玉封锁链悬吊的赤黑魔心矿核，空王座留在后方。 |
| S09 初见太平 | 战后日出，山城正在修屋、疗伤和分粮；百姓把一把普通木椅递给疲惫的顾长渊，不是宝座。 |
| S10 数十年后 | 严格对称的行政广场，中年顾长渊站在高台持空白玉令，整齐官吏列队，旧木椅被遗忘在台阶下。 |
| S11 天律 | 同一条繁荣大道左侧有诊所和粮仓，右侧是审查关卡；顾长渊立于高桥，护城结界与控制栏栅使用同一玉光。 |
| S12 英雄与恶龙 | 空旷玉殿中顾长渊按住胸口，六道玉印在墙面投下巨大中国龙阴影，胸前只有一条细小赤玉裂纹。 |
| S13 界碑苏醒 | 第一人称雨夜泥地，手掌向碑林中央巨碑爬行，月光和孤灯建立冷色引导。 |
| S14 片名背景 | 雨夜山海与左下方孤独界碑，远处一道玉色闪电，中央偏右保留大面积无字留白供后期标题。 |
