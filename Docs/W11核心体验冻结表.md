# W11《太虚问道》核心体验冻结表

> 版本：W11-GD-v1  
> 日期：2026-08-29  
> 状态：用户已确认的设计决策；未在代码中完成的条目必须继续标记为计划  
> 作用：本文件是 W11 核心玩法决策的权威入口。其他 W11 文档若与本文件冲突，以本文件为准，并区分“已实现”与“已确认待实现”。

## 1. 已冻结决策

| 项目 | 决策 |
|---|---|
| 普通攻击 | 普通攻击本身也是技能，由当前装备的 `BasicAttackAbility` 定义决定攻击形态、数值、范围、频率和命中规则，不按角色姓名硬编码。 |
| 主动技能 | 每名玩家拥有四个主动技能逻辑槽，玩家可见为 `Q / W / E / R`。技能槽可更换和成长。 |
| 角色与技能 | 所有角色共用同一套技能定义、规则效果和技能表现资源。角色只提供外观、通用动作和先天属性，不制作“角色 × 技能”规则或特效副本。 |
| 闪避 | 闪避是所有角色都拥有的基础能力，不占用普通攻击或 `Q / W / E / R` 技能槽。 |
| 单局长度 | 一局目标约 50 分钟；具体阶段时间允许数据化微调。 |
| 首领结构 | 一局依次经历五场章节小 Boss 战和一场最终 Boss 战。每个章节小 Boss 是章节门槛，最终 Boss 是整局结算门槛。 |
| 关卡结构 | 使用章节路线。章节内由地图提供战斗、事件、休整、仙坊和支路节点；每章终点固定为该章小 Boss。 |
| 仙坊 | 仙坊是否出现、出现次数和位置由章节地图节点决定，不再规定每场战斗后必定进入仙坊。 |
| 单人死亡 | 气血归零立即结束当前局内构筑并开始下一次轮回；死亡不是原地复活，也不从当前章节继续。 |
| 成长内容 | 局内升级同时包含数值提升和新战斗行为。修为负责稳定数值，秘籍主要修改技能行为，宝物主要提供条件触发和规则变化。 |
| 联机共同决策 | 章节路线、共享事件、剧情选项和结局选择由房主决定。个人修为候选、技能配置、秘籍、宝物和个人仙坊仍由各玩家自己决定。 |

## 2. 输入与技能边界

目标规则如下：

- `BasicAttackAbility` 是独立的普通攻击技能槽，不占用 `Q / W / E / R`；
- `Q / W / E / R` 是四个主动技能的逻辑槽名，技能可以是输出、控制、位移、护障、治疗或召唤；
- 闪避是角色固有战斗动作，拥有独立冷却、无敌时间、位移距离和服务器校验；
- 所有输入都只提交技能或闪避请求，伤害、治疗、护障、位移合法性和命中仍由服务器决定；
- 技能效果与角色表现严格解耦。任意角色装备同一技能时，使用同一份 `AbilityDefinition` 和 `SkillVisualDefinition`。

当前原型使用方向键移动、`F` 朝角色当前朝向施放共享普通攻击、`Q / W / E / R` 依次触发 `Active1～Active4`、`Space` 通用闪避；战斗中保留可见鼠标。四个主动槽均可复制、装备、替换和升级，未装备槽会在 HUD 明确显示“未装备”。角色平面约束使用实际出生高度；普通攻击在服务器碰撞 Sweep 外增加胶囊尺寸感知的近身边缘补偿，仍拒绝身后和超距目标。该键鼠布局是当前试玩默认值，仍须支持重绑定，不能据此提前冻结手柄布局。

## 3. 50 分钟章节路线

推荐时间预算不是硬锁帧数，而是用于控制内容密度：

```text
序章与开局             3～5 分钟
第一至第五章           每章约 7～8 分钟
  ├── 章节路线节点
  ├── 战斗 / 事件 / 休整 / 仙坊
  └── 章节小 Boss
最终 Boss 与结算       8～10 分钟
总计                   约 45～55 分钟，目标中位数约 50 分钟
```

每章可以有不同路线和地图节点，但必须满足：

- 玩家一定能识别本章目标、当前路线和小 Boss 位置；
- 仙坊是地图节点，不是战斗状态机的固定后继阶段；
- 绕行支路必须提供明确收益与时间成本；
- 五个小 Boss 分别检验不同构筑能力，不能只是生命更高的普通敌人；
- 最终 Boss 检验整局构筑，并承接本轮剧情选择与结局条件。

> 2026-08-30 工程候选说明：当前可运行候选为每章各一场普通战斗、一个事件、一个休整、一个仙坊和一个章节小 Boss，外加顾长渊最终 Boss。该组合只用于验证五章路由、首领阶段和安全续玩，不表示节点具体数量已经冻结；真人验收前章节证据必须保持 `contentFrozen=false`。

## 4. 轮回保留规则

第 7 项采用“保留认知与内容解锁，不保留局内战力”的方案。这样既符合镇世阵回溯的世界观，也避免跨局永久数值破坏肉鸽公平起点。

### 4.1 死亡后保留

- 已发现的众生证词、旧日残片、史料和图鉴条目；
- 已完成的关键人物关系阶段和被正式确认的剧情承诺；
- 已见结局、轮回次数、最高抵达章节和 Boss 档案；
- 新技能、秘籍、宝物、事件和难度的横向解锁资格；
- 外观、音乐、插画、回忆演出、成就与本地设置；
- 用于开启新对白、新路线和真结局条件的稳定叙事标记。

横向解锁只扩大选择和玩法，不直接增加永久气血、攻伐、护体、会心、灵石收入或商品品阶。为避免解锁池越来越稀释，玩家应能在开局管理启用池，或由章节和门派标签限制候选池。

### 4.2 死亡后清空

- 当前角色与门派选择；
- 普通攻击技能、`Q / W / E / R` 装备和局内技能等级；
- 修为层数、全部局内属性修正和临时状态；
- 秘籍、参悟层次、宝物和消耗品；
- 灵石、当前气血/真元、商店候选、路线 Seed 和未完成节点；
- 只在本轮成立、尚未完成章节确认的临时关系和任务状态。

### 4.3 证词与关系的提交时点

- 单纯阅读或发现的史料，在抵达下一个安全节点时写入界痕档案；
- 影响人物信任、军印、医馆或制度路线的选择，只有完成对应章节小 Boss 后才写入长期档案；
- 结局与最终制度选择只有完成最终 Boss 和结算后才写入；
- 因此死亡仍能留下知识，但不能靠进入事件后立即自杀来完成关键人物路线。

### 4.4 退出续玩与死亡轮回必须分开

50 分钟单局必须支持安全续玩：

- 主动退出、程序崩溃或断电不等于角色死亡；
- 单人只在已完成的地图安全节点保存一个活动局快照；
- 快照记录 `RunId`、内容版本、Seed、章节节点、构筑、经济和生命资源；
- 读取“继续问道”只能恢复该安全节点，不能恢复战斗中任意一帧；
- 气血归零时先删除活动局快照，再提交允许保留的界痕档案并开始新轮回。

联机活动局由房主保存。共同路线和剧情结果以房主决定为准；实际参与并抵达提交点的客户端可以把已见史料和结局写入自己的档案，但不能在未参与相应章节时直接获得人物关系完成标记。

## 5. 仍待冻结的问题

以下问题没有在本轮决定中得到答案，不能擅自写成已确认：

1. 当前 `F + Q / W / E / R + Space` 试玩布局是否作为发布默认值，以及对应手柄布局与完整重绑定界面；
2. 普通攻击使用方向键、鼠标瞄准、自动索敌还是可切换方案；
3. 合作倒地、救援、全队失败和章节复归规则；
4. 团队修为、生命/真元掉落与个人实例化的最终规则；
5. 每章普通战斗、事件、休整与仙坊节点的具体数量；
6. 房主掉线后的 50 分钟长局处理：直接结束、允许重连还是主机迁移；
7. 横向解锁池的启用、禁用和防稀释界面。
