# 《月圆之夜》单机版机制与资料边界

调研截止：2026-08-15。

本文用于给 WorldWalker 的 W01 西幻卡牌世界建立机制参考基线。结论先行：**第一阶段应参考《月圆之夜》的经典模式，而不是把所有单机模式混成一套规则**。经典模式最接近“玩家在世界中探索、构筑牌组、与拥有自己牌组和被动的单个对手进行回合制战斗”的目标；镜中记忆、愿望之夜、小狗头人历险记和秘宝对决应作为独立扩展研究。

本文是内部设计研究，不授权在产品中使用原作卡图、角色形象、剧情、音乐、卡名或规则文案。正式游戏应保留机制层启发，但使用 WorldWalker 自己的世界观、名称、数值、卡图和资产。

## “所有卡牌”目前能确认到什么程度

官方只公开汇总数量和 DLC 增量，没有找到官方逐卡 API 或当前版本导出。因此不能诚实声称网页调研已经确认了当前版本的每一张卡。现有证据分为四层：

| 层级 | 来源 | 能确认的内容 | 不能确认的内容 |
|---|---|---|---|
| A | 官方商店、官网、官方公告 | 模式、职业、宣传总量、DLC 和发布时间 | 逐卡名、费用、星级、逐敌人牌组 |
| B | [2026 社区图鉴仓库](https://github.com/CypressVillage/moonCards) | 经典满星卡图 696、图鉴外 35、日记图鉴 85、日记外初始怪物 14、怪物图鉴 149、技能牌 17 等目录计数 | 编号图片不能直接提供一张可审计的当前卡名表 |
| C | 仓库中的 2023 逆向整理表 | CardId、名称、类型、资源消耗、职业权重、升级链和敌方权重等结构字段 | 数据快照停在 2023；筛选“正式卡”的规则不是官方定义 |
| D | 2024 BWIKI 与 2022 TapTap 玩家表 | 可搜索的中文卡名、类型、职业、规则线索和对手牌名集合 | 页面自述或客观上不完整，且缺当前版本戳 |

## “所有对手和对手卡牌”目前能确认到什么程度

官方当前宣传为 142 位对手，但没有公开逐对手牌组。

[TapTap 2022 怪物表](https://www.taptap.cn/moment/277583495046368195)可结构化得到 147 行：114 个普通索引、33 个 Boss 索引。它不是 147 个当前经典模式独立角色，因为：

- 明示包含 3 个“小红帽日记”变体；
- “小红帽”同时作为普通和 Boss 出现；
- 来源混排模式和战斗形态，作者还明确写了“未补完”；
- 折叠已知重复关系后仍有一个无法由公开证据解释的差额，所以不能强行把 147 映射成官方 142。

牌组覆盖情况：

- 133 行列出固定牌名；
- 3 行是动态牌组：魔镜复制玩家牌、贵族画像随机取得职业牌、狼王按基础模块＋8 选 4 特殊模块＋补卡构筑；
- 11 行没有公开牌组；
- 固定表共出现 264 个规范化卡名；
- 来源省略普攻、copies、星级，并说明怪物牌组会随等级变化，所以这些牌名只是**最低确认集合**，不是可直接还原的精确套牌。

147 行对手、264 个固定牌组卡名和 2023 敌方权重候选表见[经典模式对手与敌方卡牌核验索引](./月圆之夜经典模式对手与敌方卡牌核验索引.md)。

## 经典模式的机制骨架

以下是适合 W01 参考的高层机制，不是对单卡文案的复制。

### 探索层

1. 一局由多个章节组成；玩家在若干可见页面/事件中选择前进方向。
2. 页面可能是普通战斗、精英/Boss、商店、宝箱、祝福、升级、删牌、回复或剧情事件。
3. 牌组在一局内持续成长；卡牌可获得、升级、复制或移除。
4. 祝福属于长期被动，不与手牌混放；角色技能也独立于普通卡牌。
5. 名声、勇气、事件选择和隐藏条件影响故事与最终对手。
6. 对手不仅有生命和牌组，还有会改变规则的独立被动。

### 战斗层

1. 基本形态是玩家与单个对手轮流行动，双方各自抽牌、出牌和结算状态。
2. 经典卡牌大类包括攻击、行动、法力、装备、咒术、反制、祷告和特殊牌。
3. 资源不是统一能量：行动牌消耗行动力，咒术通常消耗法力；攻击、装备、反制和祷告又有自己的时机与限制。
4. 装备进入持续生效区；反制响应敌方特定出牌；祷告在倒计时后释放；这些区域和时序构成主要复杂度。
5. 抽牌、弃牌、洗牌、移除、复制、生成、升级和费用变化共同构成牌组循环。
6. 火、雷、冰/寒冷、毒、穿刺、护甲、治疗、吸血、易伤等伤害或状态体系支持不同职业流派。
7. 怪物的“被动＋牌组”共同定义战斗谜题；只换数值而不换规则的敌人无法得到相同体验。

## 对 3D 版 W01 的直接启发

| 原作抽象 | W01 的 3D 对应 |
|---|---|
| 三张页面选一路 | 实体岔路、可预览地标和可回看的路线选择 |
| 页面事件 | 可接近的 NPC、祭坛、商店、营地、宝箱和环境事件 |
| 单个怪物页面 | 场景中可见、可绕行或挑战的 3D 对手 |
| 对手被动 | 角色外观、环境特效和战斗 UI 同时表达的规则钩子 |
| 敌人牌组 | 敌方真实抽牌/出牌区，而不是固定四步脚本 |
| 商店/升级/删牌 | 3D 商人、铁匠、修女或炼金台交互 |
| 章节 Boss | 远处可见的大型地标、门禁和专属竞技场 |
| 剧情分支 | 中文 NPC 对话、名声/勇气选择和不同返回路径 |

因此，当前 W01 最值得优先演进的不是增加更多静态布景，而是把“固定意图循环”逐步升级为：敌人拥有抽牌堆、手牌、费用、装备/反制区和独立被动；探索路线则提供获得牌、升级、删牌、祝福和事件的 3D 节点。

## W01 当前落地快照（2026-08-16）

本轮先实现机制骨架，不把不完整社区数据伪装成原作精确导出：

- 四层路线已接入普通战/精英、事件、休整和章节 Boss；选战斗后才生成 3D 对手。
- 玩家拥有抽牌、手牌、弃牌、消耗、装备区，以及分离的行动力/法力；敌人拥有独立牌组、相同基础牌区、装备区和反制区。
- 每次胜利随机三选一并把一张加入本次旅途；事件支持恢复、生命代价换牌、删基础牌和下一战格挡。
- GameInstance 保存旅途生命、获得/移除牌、路线深度、活动节点和待兑现增益；尚未写磁盘存档。
- 已生成候选为 18 张玩家定义、15 张敌方定义、7 个对手定义。当前只有 6 张规则线索足够的女骑士候选进入奖励池；未实现复制攻击、条件成长、玩家反制和祷告倒计时的牌继续隔离。
- 对手可见牌名只使用索引中的最低确认集合；copies、星级、生命、出牌上限和未公开数值均标记为 `project-tuned`。

## 继续提高还原度前必须完成的确认

1. 固定一个参考版本与平台；推荐以当前移动版经典模式为总量口径，以 2023 逆向表＋2024 BWIKI 为逐名底稿。
2. 在游戏内图鉴人工核对 2026 社区仓库的 696 个经典满星编号，补齐当前卡名、类型、费用和升级差异。
3. 对 142 位对手逐个记录：章节、难度档、生命、被动、牌组 copies、星级和抽牌/行动资源。
4. 将临时衍生牌、怪物专用牌、技能、祝福、事件和历史联动分表，不能都算入“玩家卡”。
5. 完成上述快照后，再设计 WorldWalker 自己的原创职业、卡池和对手；不要直接照搬原作名称、数值或美术。
