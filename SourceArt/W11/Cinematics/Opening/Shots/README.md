# W11 Opening Shot Packages

每个目录是一份可独立交付的镜头制作包。制作时先阅读镜头目录内的 `SHOT_PACKAGE.md`，并把其中“镜头画面提示词”与上级的 `W11_Opening_GlobalPrompt.txt` 合并后提交给生成工具。

为方便直接上传，每个镜头目录还会包含独立副本 `00_READ_ME_FIRST.txt` 与 `00_GLOBAL_STYLE_AND_NEGATIVE.txt`。`ShotPackages_Zip/` 中保存 14 个同名 ZIP；上传一个 ZIP 即可把该镜头的说明和现有参考图完整交给支持文件上传的视频 AI。

## 统一交付规范

- 工作分辨率：1920×1080，24 fps，16:9。
- 每个目录的最终片段使用目录中规定的文件名。
- AI 原始输出保留无旁白、无字幕、无题名的 Clean 版本。
- 中文文字只在剪辑软件中添加。
- 角色或场景不稳定时，优先缩短片段，不用高速运动掩盖错误。
- `S14` 与 `S13` 重叠，不增加总片长；成片总长度为 96 秒。
