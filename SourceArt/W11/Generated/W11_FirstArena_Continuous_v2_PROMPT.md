# W11 First Arena Continuous v2

Generation mode: built-in imagegen.

Reference image: `W11_Arena_Background_v1.png` (visual style, palette, materials,
lighting, and top-down composition only).

Use case: stylized-concept

Asset type: production game background for the first W11 combat arena, one
single square bitmap canvas.

Primary request: create one seamless, continuous square top-down orthographic
Chinese xianxia roguelite combat arena, using the referenced complete arena
image only as the visual style and material reference. The result must be one
coherent scene, not a collage and not four tiles.

Scene/backdrop: a large circular teal-jade flagstone training arena centered in
frame, with subtle continuous concentric stonework and restrained aged-gold
inlay; beyond the arena rim, cohesive bamboo, lotus water, mossy rocks, small
ruined stone structures, waterfalls and cool mist continue naturally around all
four outer edges.

Style/medium: polished painterly realistic fantasy game environment, matching
the reference palette, brushwork, lighting, stone scale and xianxia atmosphere.

Composition/framing: exact straight-down orthographic view; square 1:1
composition; arena center exactly at image center; combat-readable low-contrast
floor occupies most of the canvas; outer scenery confined to the perimeter;
provide generous continuous overscan on every side for a camera that follows the
player.

Lighting/mood: cool teal moonlit ambience with sparse warm lantern accents; even
illumination across the playable floor.

Constraints: a single uninterrupted canvas; stone courses and circular inlays
must remain geometrically continuous across the entire image; no seams, quadrant
boundaries, abrupt color shifts, borders, split panels, or repeated tile
patterns; keep the center clear for characters and telegraphs; no characters,
monsters, UI, text, logos, watermarks, perspective horizon, or cropped arena
edge.
